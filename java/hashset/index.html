5 · HashSet<E>, LinkedHashSet, TreeSet

LevelR
PrerequisitesHashMap
Estimated time15 min
ProgressionWarm-up → Easy → Medium → Hard

Intuition

Membership in average O(1). TreeSet adds sorted order at O(log n) per op — pick by whether you need ordering.

Common mistakes

  • Using contains() in a loop and accidentally staying O(n²) elsewhere — the set part is fine, check the rest.

Quick reference

5 · HashSet<E>, LinkedHashSet, TreeSet

Collection of unique elements. Critical for duplicate detection and membership testing.

import java.util.HashSet;
import java.util.LinkedHashSet;
import java.util.TreeSet;
import java.util.Set;

// Creation
Set<Integer> set = new HashSet<>();
Set<Integer> set = new HashSet<>(Arrays.asList(1, 2, 3));
Set<Integer> set = new LinkedHashSet<>();   // Insertion order
Set<Integer> set = new TreeSet<>();          // Sorted order
Set<Integer> set = Set.of(1, 2, 3);          // Immutable (Java 9+)

// Core Operations
set.add(element);           // true if added, false if already present — O(1)
set.remove(element);        // true if removed — O(1)
set.contains(element);      // O(1)
set.size();
set.isEmpty();
set.clear();

// Bulk Operations (Set Theory)
set.addAll(other);          // Union
set.retainAll(other);       // Intersection (modifies set in place!)
set.removeAll(other);       // Difference
set.containsAll(other);     // Subset check

// Iteration
for (int val : set) { }
set.forEach(System.out::println);
set.stream().sorted().forEach(System.out::println);

// Conversion
List<Integer> list = new ArrayList<>(set);
Integer[] arr = set.toArray(new Integer[0]);

TreeSet — Sorted Set with Navigation

TreeSet<Integer> ts = new TreeSet<>();
ts.addAll(Arrays.asList(10, 20, 30, 40, 50));

ts.first();              // 10 — smallest
ts.last();               // 50 — largest
ts.lower(30);            // 20 — strictly less than
ts.higher(30);           // 40 — strictly greater than
ts.floor(30);            // 30 — less than or equal
ts.ceiling(30);          // 30 — greater than or equal
ts.headSet(30);          // {10, 20} — elements < 30
ts.tailSet(30);          // {30, 40, 50} — elements >= 30
ts.subSet(20, 50);       // {20, 30, 40} — [20, 50)
ts.subSet(20, true, 50, true); // {20, 30, 40, 50} — [20, 50]
ts.pollFirst();          // Remove and return smallest
ts.pollLast();           // Remove and return largest
ts.descendingSet();      // Reverse order view
