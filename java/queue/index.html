8 · Queue, Deque & PriorityQueue

LevelR
PrerequisitesArrays
Estimated time25 min
ProgressionWarm-up → Easy → Medium → Hard

Intuition

FIFO (Queue), double-ended (Deque), and min/max-first (PriorityQueue). BFS needs a queue; sliding-window max needs a deque.

Common mistakes

  • PriorityQueue iteration order is NOT sorted — only poll() order is.
  • ArrayDeque forbids nulls; LinkedList allows them — don't mix assumptions.

Quick reference

8 · Queue, Deque & PriorityQueue

Queue (FIFO)

import java.util.Queue;
import java.util.ArrayDeque;

Queue<Integer> queue = new ArrayDeque<>();  // ✅ Best implementation
// Queue<Integer> queue = new LinkedList<>();  // Also works but slower

queue.offer(10);          // Enqueue — O(1)
queue.offer(20);
queue.offer(30);

queue.peek();             // 10 — front element — O(1)
queue.poll();             // 10 — dequeue front — O(1)
queue.isEmpty();
queue.size();

// BFS pattern
Queue<int[]> queue = new ArrayDeque<>();
queue.offer(new int[]{startRow, startCol});
while (!queue.isEmpty()) {
    int[] curr = queue.poll();
    // process and add neighbors
}

Deque (Double-Ended Queue)

Deque<Integer> deque = new ArrayDeque<>();

deque.offerFirst(1);      // Add to front — O(1)
deque.offerLast(2);       // Add to back — O(1)
deque.peekFirst();        // View front — O(1)
deque.peekLast();         // View back — O(1)
deque.pollFirst();        // Remove front — O(1)
deque.pollLast();         // Remove back — O(1)

PriorityQueue (Min-Heap by default)

import java.util.PriorityQueue;

// Min-Heap (default)
PriorityQueue<Integer> minHeap = new PriorityQueue<>();

// Max-Heap
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);

// Custom comparator — sort by second element of int[]
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);

// Multi-field comparator
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> {
    if (a[0] != b[0]) return a[0] - b[0];  // First by cost
    return a[1] - b[1];                     // Then by index
});

// Operations
pq.offer(element);        // Insert — O(log n)
pq.peek();                // Min/Max element — O(1)
pq.poll();                // Remove min/max — O(log n)
pq.remove(element);       // Remove specific — O(n)
pq.contains(element);     // O(n)
pq.size();
pq.isEmpty();
pq.toArray();

// Build from collection — O(n) via heapify
PriorityQueue<Integer> pq = new PriorityQueue<>(list);
