3 · LinkedList<E>

LevelR
PrerequisitesArrays
Estimated time20 min
ProgressionWarm-up → Easy → Medium → Hard

Intuition

Nodes + pointers: O(1) insert at a known node, O(n) indexed access. Rare in contests except as a concept; know reversal and fast/slow.

Common mistakes

  • Losing the head reference during rewiring — save next first.
  • Forgetting dummy head for deletions at position 0.

Quick reference

3 · LinkedList<E>

Doubly-linked list. Implements both List and Deque. Best for frequent insertion/deletion at both ends.

import java.util.LinkedList;

LinkedList<Integer> ll = new LinkedList<>();

// Deque operations (O(1) each)
ll.addFirst(1);          // Push to front
ll.addLast(2);           // Push to back
ll.offerFirst(0);        // Add to front (returns boolean)
ll.offerLast(3);         // Add to back (returns boolean)
ll.getFirst();           // Peek front (throws if empty)
ll.getLast();             // Peek back (throws if empty)
ll.peekFirst();           // Peek front (returns null if empty)
ll.peekLast();            // Peek back (returns null if empty)
ll.removeFirst();         // Pop front (throws if empty)
ll.removeLast();          // Pop back (throws if empty)
ll.pollFirst();           // Pop front (returns null if empty)
ll.pollLast();            // Pop back (returns null if empty)

// List operations
ll.add(element);          // Append — O(1)
ll.add(index, element);   // Insert at index — O(n) to find position
ll.get(index);            // O(n) — must traverse
ll.set(index, element);   // O(n)
ll.remove(index);         // O(n) to find, O(1) to unlink
ll.size();
ll.isEmpty();
ll.contains(element);     // O(n)

// Stack operations
ll.push(element);         // Same as addFirst
ll.pop();                 // Same as removeFirst
ll.peek();                // Same as peekFirst

// Iterator-based removal (efficient)
Iterator<Integer> it = ll.iterator();
while (it.hasNext()) {
    if (it.next() == target) it.remove();  // O(1) removal via iterator
}
OperationTime
addFirst / addLastO(1)
removeFirst / removeLastO(1)
get(index)O(n)
add(index) / remove(index)O(n)
containsO(n)
💡 Use ArrayDeque instead of LinkedList for stack/queue operations — it's faster due to cache locality and no node allocation overhead.
