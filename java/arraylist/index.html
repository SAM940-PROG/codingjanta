2 · ArrayList<E>

LevelR
PrerequisitesArrays
Estimated time20 min
ProgressionWarm-up → Easy → Medium → Hard

Intuition

A resizable array: amortized O(1) append, O(n) mid-insert. Default list for contests unless you need queue/deque semantics.

Common mistakes

  • Removing inside a for-each (ConcurrentModificationException) — use iterator/removeIf or index loop backwards.
  • Repeated add(0,..) is O(n) each — use deque for front inserts.

Quick reference

2 · ArrayList<E>

Dynamic array backed by a resizable array. Best for random access and iteration.

import java.util.ArrayList;
import java.util.List;
import java.util.Collections;

// Creation
List<Integer> list = new ArrayList<>();
List<Integer> list = new ArrayList<>(initialCapacity);
List<Integer> list = new ArrayList<>(Arrays.asList(1, 2, 3));
List<Integer> list = List.of(1, 2, 3);           // Immutable (Java 9+)
List<Integer> list = new ArrayList<>(List.of(1,2,3)); // Mutable copy

// Adding
list.add(element);                // Append to end — O(1) amortized
list.add(index, element);        // Insert at index — O(n)
list.addAll(otherList);           // Append all — O(m)
list.addAll(index, otherList);    // Insert all at index — O(n+m)

// Accessing
list.get(index);                  // O(1)
list.set(index, element);        // O(1) — replace element
list.indexOf(element);            // O(n) — first occurrence
list.lastIndexOf(element);        // O(n)
list.contains(element);           // O(n)

// Removing
list.remove(index);               // O(n) — shifts elements
list.remove(Integer.valueOf(42)); // Remove by value (first occurrence)
list.removeAll(otherList);        // Remove all matching
list.retainAll(otherList);        // Keep only matching (intersection)
list.clear();                     // Remove all

// Size & State
list.size();                      // Number of elements
list.isEmpty();                   // true if empty

// Iteration
for (int val : list) { }
for (int i = 0; i < list.size(); i++) { list.get(i); }
list.forEach(x -> System.out.println(x));

// Sorting
Collections.sort(list);                          // Ascending
Collections.sort(list, Collections.reverseOrder()); // Descending
list.sort(Comparator.naturalOrder());             // Java 8+
list.sort((a, b) -> b - a);                      // Custom descending

// Conversion
int[] arr = list.stream().mapToInt(Integer::intValue).toArray();
List<Integer> list = Arrays.stream(arr).boxed().collect(Collectors.toList());
Object[] objArr = list.toArray();
Integer[] intArr = list.toArray(new Integer[0]);

// Sublist (view, not copy)
List<Integer> sub = list.subList(from, to);       // [from, to)

// Useful
Collections.reverse(list);
Collections.swap(list, i, j);
Collections.frequency(list, element);
Collections.min(list);
Collections.max(list);
Collections.shuffle(list);
Collections.unmodifiableList(list);               // Read-only wrapper
OperationTime
get / setO(1)
add (end)O(1) amortized
add (index) / removeO(n)
contains / indexOfO(n)
sortO(n log n)
