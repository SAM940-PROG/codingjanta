4 · HashMap<K, V> & LinkedHashMap & HashTable

LevelR
PrerequisitesArrays
Estimated time25 min
ProgressionWarm-up → Easy → Medium → Hard

Intuition

Key→value in average O(1). The counting/grouping workhorse; iteration order is unspecified (use LinkedHashMap when order matters).

Common mistakes

  • Using mutable keys or arrays as keys (no proper equals/hashCode).
  • Assuming iteration order — it is unspecified.

Quick reference

4 · HashMap<K, V> & LinkedHashMap & HashTable

Hash-table based Map. O(1) average for get/put. Most important data structure for DSA.

import java.util.HashMap;
import java.util.LinkedHashMap;
import java.util.Map;

// Creation
Map<String, Integer> map = new HashMap<>();
Map<String, Integer> map = new HashMap<>(capacity, loadFactor);
Map<String, Integer> map = new LinkedHashMap<>();  // Maintains insertion order
Map<String, Integer> map = Map.of("a", 1, "b", 2); // Immutable (Java 9+)

// Putting
map.put(key, value);                // Insert or update — O(1) avg
map.putIfAbsent(key, value);        // Only if key not present
map.putAll(otherMap);               // Copy all entries

// Getting
map.get(key);                       // Returns value or null
map.getOrDefault(key, defaultVal);  // Returns value or default — VERY useful
map.containsKey(key);               // O(1) avg
map.containsValue(value);           // O(n) — must scan all values

// Removing
map.remove(key);                    // O(1) avg
map.remove(key, value);             // Remove only if key maps to value
map.clear();

// Size
map.size();
map.isEmpty();

// Compute / Merge — EXTREMELY useful for DSA
map.merge(key, 1, Integer::sum);           // Frequency counting in ONE line!
map.compute(key, (k, v) -> v == null ? 1 : v + 1);   // Same as above
map.computeIfAbsent(key, k -> new ArrayList<>());    // Adjacency list builder!
map.computeIfPresent(key, (k, v) -> v - 1);

// Iteration
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    String k = entry.getKey();
    int v = entry.getValue();
}
for (String key : map.keySet()) { }
for (int val : map.values()) { }
map.forEach((k, v) -> System.out.println(k + ": " + v));

// Views
Set<String> keys = map.keySet();
Collection<Integer> vals = map.values();
Set<Map.Entry<String,Integer>> entries = map.entrySet();

// Replace
map.replace(key, newValue);
map.replace(key, oldValue, newValue);
map.replaceAll((k, v) -> v * 2);

Common Patterns

// Frequency Map
Map<Integer, Integer> freq = new HashMap<>();
for (int num : arr) {
    freq.merge(num, 1, Integer::sum);
}

// Group By (Anagram grouping, etc.)
Map<String, List<String>> groups = new HashMap<>();
for (String s : strs) {
    char[] ca = s.toCharArray();
    Arrays.sort(ca);
    String key = String.valueOf(ca);
    groups.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
}

// Two Sum Pattern
Map<Integer, Integer> seen = new HashMap<>();
for (int i = 0; i < nums.length; i++) {
    int complement = target - nums[i];
    if (seen.containsKey(complement)) return new int[]{seen.get(complement), i};
    seen.put(nums[i], i);
}

// Index Mapping
Map<Integer, List<Integer>> indexMap = new HashMap<>();
for (int i = 0; i < arr.length; i++) {
    indexMap.computeIfAbsent(arr[i], k -> new ArrayList<>()).add(i);
}

ℹ HashMap vs LinkedHashMap vs TreeMap
• HashMap: No order. O(1) avg. Best default choice.
• LinkedHashMap: Insertion order. Slightly more memory. Good for LRU cache.
• TreeMap: Sorted by key. O(log n). When you need sorted keys.
• Hashtable: Thread-safe but legacy. Use ConcurrentHashMap instead.
