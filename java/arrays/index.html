1 · Arrays & Strings

LevelR
PrerequisitesNone — start here
Estimated time20–30 min
ProgressionWarm-up → Easy → Medium → Hard

Intuition

An array is contiguous memory with instant indexing but costly mid-inserts. Almost every pattern assumes you can read a[i] in O(1).

Common mistakes

  • Off-by-one on last index (length-1, not length).
  • Assuming new int[n] values are meaningful — they are zeros; track filled size separately.

Quick reference

1 · Arrays & Strings

Declaration & Initialization

// 1D Array
int[] arr = new int[n];                        // default 0
int[] arr = {1, 2, 3, 4, 5};
int[] arr = new int[]{1, 2, 3};

// 2D Array
int[][] grid = new int[rows][cols];
int[][] grid = {{1,2},{3,4}};

// String to char array
char[] chars = str.toCharArray();

// Array copy
int[] copy = Arrays.copyOf(arr, arr.length);
int[] sub  = Arrays.copyOfRange(arr, from, to);  // [from, to)
System.arraycopy(src, srcPos, dest, destPos, length);

Essential Array Operations

Arrays.sort(arr);                              // O(n log n) — Dual-Pivot Quicksort
Arrays.sort(arr, from, to);                    // Sort subarray [from, to)
Arrays.sort(arr, Collections.reverseOrder());  // Descending (Integer[] only)
Arrays.fill(arr, value);                       // Fill entire array
Arrays.fill(arr, from, to, value);             // Fill range [from, to)
Arrays.binarySearch(arr, key);                 // Must be sorted first! Returns index or -(insertionPoint)-1
Arrays.equals(arr1, arr2);                     // Element-wise comparison
Arrays.deepEquals(arr2D_1, arr2D_2);           // Deep comparison for multi-dim
Arrays.stream(arr).sum();                      // Sum of array
Arrays.stream(arr).max().getAsInt();           // Max value
Arrays.stream(arr).min().getAsInt();           // Min value

Essential String Operations

String s = "hello world";

s.length();                    // 11
s.charAt(0);                   // 'h'
s.substring(0, 5);             // "hello"  [start, end)
s.indexOf("world");            // 6
s.lastIndexOf('l');            // 9
s.contains("llo");             // true
s.startsWith("hel");           // true
s.endsWith("rld");             // true
s.equals("hello world");       // true (NEVER use == for strings)
s.equalsIgnoreCase("HELLO WORLD"); // true
s.compareTo("abc");            // lexicographic comparison
s.toUpperCase();
s.toLowerCase();
s.trim();                      // remove leading/trailing whitespace
s.strip();                     // Unicode-aware trim (Java 11+)
s.replace('l', 'L');           // "heLLo worLd"
s.replace("world", "java");   // "hello java"
s.split(" ");                  // {"hello", "world"}
s.toCharArray();               // char[]
String.join("-", arr);         // Join string array with delimiter
String.valueOf(123);           // "123"
Integer.parseInt("123");       // 123
Character.isDigit('5');        // true
Character.isLetter('a');       // true
Character.isLetterOrDigit('a'); // true
