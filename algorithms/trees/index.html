Intuition

Hierarchies with O(log n) BST ops when balanced. Traversals (in/pre/post/level) are the vocabulary; BST order is the tool.

Learn: Tree traversals, BST operations, LCA, serialization, level-order  ·  Practice: Warm-ups -> Easy -> Medium -> Hard

How to recognize this pattern

Reach for it when:
  • Hierarchies, ancestry, nesting depth.
  • BST order statistics / validation / search.
  • Level-by-level or path questions on trees.
  • Diameter/LCA/subtree shapes.
Red flags — probably NOT this:
  • General graph with cycles — use graph traversal instead.
  • Only sorted-array behavior needed — BST is overkill.

Worked example — Maximum depth

Problem. Tree [3,9,20,null,null,15,7]. Height?

  1. What should we notice? Height is recursive: 1 + max(children); null contributes 0.
  2. Naive thought. BFS counting levels: fine, but recursion mirrors the definition.
  3. Key observation. depth(node) = 0 if null else 1+max(depth(L),depth(R)). Solve children, combine — postorder thinking.
  4. Optimized strategy. depth(9)=1, depth(15)=depth(7)=1 → depth(20)=2 → depth(3)=1+max(1,2)=3.
  5. Step-by-step. Validation twin: carry (low,high) bounds down; each node must fit, bounds tighten per side.
  6. Final answer. 3.
  7. Complexity. O(n) time, O(height) stack.
  8. What to remember. Null=0 base; combine children. BST work = bounds propagation.

Quick reference

Topic 11 · Trees (Binary Tree, BST)

When would you actually use this? Use trees when data has hierarchical relationships. BSTs enable O(log n) search. Tree traversals (inorder, preorder, postorder, level-order) are foundational for many problems.

Algorithms

// TreeNode definition
class TreeNode {
    int val;
    TreeNode left, right;
    TreeNode(int val) { this.val = val; }
}

// ── DFS Traversals ──
// Inorder (Left → Root → Right) — gives sorted order for BST
void inorder(TreeNode root) {
    if (root == null) return;
    inorder(root.left);
    process(root.val);
    inorder(root.right);
}

// Preorder (Root → Left → Right) — serialize tree
void preorder(TreeNode root) {
    if (root == null) return;
    process(root.val);
    preorder(root.left);
    preorder(root.right);
}

// Postorder (Left → Right → Root) — delete tree, evaluate expressions
void postorder(TreeNode root) {
    if (root == null) return;
    postorder(root.left);
    postorder(root.right);
    process(root.val);
}

// Iterative Inorder (using stack)
List<Integer> inorderIterative(TreeNode root) {
    List<Integer> result = new ArrayList<>();
    Deque<TreeNode> stack = new ArrayDeque<>();
    TreeNode curr = root;
    while (curr != null || !stack.isEmpty()) {
        while (curr != null) { stack.push(curr); curr = curr.left; }
        curr = stack.pop();
        result.add(curr.val);
        curr = curr.right;
    }
    return result;
}

// ── BFS / Level Order ──
List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> result = new ArrayList<>();
    if (root == null) return result;
    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);
    while (!queue.isEmpty()) {
        int size = queue.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            level.add(node.val);
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        result.add(level);
    }
    return result;
}

// ── Height / Depth ──
int height(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(height(root.left), height(root.right));
}

// ── BST Search ──
TreeNode search(TreeNode root, int target) {
    if (root == null || root.val == target) return root;
    return target < root.val ? search(root.left, target) : search(root.right, target);
}

// ── BST Insert ──
TreeNode insert(TreeNode root, int val) {
    if (root == null) return new TreeNode(val);
    if (val < root.val) root.left = insert(root.left, val);
    else root.right = insert(root.right, val);
    return root;
}

// ── BST Delete ──
TreeNode delete(TreeNode root, int val) {
    if (root == null) return null;
    if (val < root.val) root.left = delete(root.left, val);
    else if (val > root.val) root.right = delete(root.right, val);
    else {
        if (root.left == null) return root.right;
        if (root.right == null) return root.left;
        TreeNode min = root.right;
        while (min.left != null) min = min.left;
        root.val = min.val;
        root.right = delete(root.right, min.val);
    }
    return root;
}

// ── Lowest Common Ancestor (BST) ──
TreeNode lcaBST(TreeNode root, TreeNode p, TreeNode q) {
    if (root.val > p.val && root.val > q.val) return lcaBST(root.left, p, q);
    if (root.val < p.val && root.val < q.val) return lcaBST(root.right, p, q);
    return root;
}

// ── Lowest Common Ancestor (Binary Tree) ──
TreeNode lca(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode left = lca(root.left, p, q);
    TreeNode right = lca(root.right, p, q);
    if (left != null && right != null) return root;
    return left != null ? left : right;
}

Check yourself

Three questions. Predict, don't peek — then verify against the lesson.

1. Inorder of a BST yields?

Explanation

Left < node < right at every subtree composes into global sortedness.

2. BST validation needs?

Explanation

A deep descendant can violate a distant ancestor while satisfying its parent.

3. Recursion depth risk?

Explanation

Depth = height; a 10⁵ chain breaks default stacks.
