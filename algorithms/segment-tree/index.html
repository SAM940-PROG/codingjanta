Intuition

Range query + update in O(log n): BIT for prefix sums, segtree for general merges, lazy for range updates.

Learn: Fenwick tree (BIT), segment tree, lazy propagation, range query + update  ·  Practice: Warm-ups -> Medium -> Hard

How to recognize this pattern

Reach for it when:
  • Range query + point/range update interleaved.
  • Range min/max/sum/gcd with updates.
  • Counting inversions offline.
  • Static RMQ with zero updates → sparse table is simpler.
Red flags — probably NOT this:
  • Only prefix sums, no updates → plain prefix array.
  • Updates only, no queries → difference array.

Worked example — Range sum with updates

Problem. Array [1,3,5,7,9]. Query sum(1,3), then set a[2]=6.

  1. What should we notice? Merge intervals: each tree node stores its segment sum; query touches O(log n) disjoint nodes.
  2. Naive thought. Rescan per query: O(n) each.
  3. Key observation. Build sums bottom-up. Query recurses only into overlapping children; point update rewrites one leaf path.
  4. Optimized strategy. Tree: root 25; children 9 ([0,1]) and 16 ([2,4])… query(1,3) = a[1] + node[2,3](12) = 3+12=15. Update a[2]=6: fix path 5→6, 16→17, 25→26.
  5. Step-by-step. Lazy twin: range-add stores pending tags instead of descending.
  6. Final answer. 15, then structure reflects 6.
  7. Complexity. Build O(n); query/update O(log n); 4n arrays.
  8. What to remember. Merge function + overlap cases. Lazy for range updates; BIT when the op is prefix-invertible.

Quick reference

Topic 26 · Segment Trees & Binary Indexed Trees (Fenwick)

When would you actually use this? Use segment trees or Fenwick trees for range queries and point/range updates. They enable O(log n) operations where brute force would be O(n).

Algorithm — Fenwick Tree (Binary Indexed Tree)

// Point update, range query in O(log n)
class FenwickTree {
    int[] tree;
    int n;
    
    FenwickTree(int n) { this.n = n; tree = new int[n + 1]; }
    
    // Add val to index i (1-indexed)
    void update(int i, int val) {
        for (; i <= n; i += i & (-i))
            tree[i] += val;
    }
    
    // Prefix sum [1, i]
    int query(int i) {
        int sum = 0;
        for (; i > 0; i -= i & (-i))
            sum += tree[i];
        return sum;
    }
    
    // Range sum [l, r]
    int rangeQuery(int l, int r) {
        return query(r) - query(l - 1);
    }
}

// Build from array
FenwickTree ft = new FenwickTree(n);
for (int i = 0; i < n; i++) ft.update(i + 1, arr[i]);

Algorithm — Segment Tree

// Range query + range/point update in O(log n)
class SegmentTree {
    int[] tree;
    int[] lazy;  // For lazy propagation
    int n;
    
    SegmentTree(int[] arr) {
        n = arr.length;
        tree = new int[4 * n];
        lazy = new int[4 * n];
        build(arr, 1, 0, n - 1);
    }
    
    void build(int[] arr, int node, int start, int end) {
        if (start == end) { tree[node] = arr[start]; return; }
        int mid = (start + end) / 2;
        build(arr, 2 * node, start, mid);
        build(arr, 2 * node + 1, mid + 1, end);
        tree[node] = tree[2 * node] + tree[2 * node + 1];  // Merge operation
    }
    
    // Point Update
    void update(int node, int start, int end, int idx, int val) {
        if (start == end) { tree[node] = val; return; }
        int mid = (start + end) / 2;
        if (idx <= mid) update(2 * node, start, mid, idx, val);
        else update(2 * node + 1, mid + 1, end, idx, val);
        tree[node] = tree[2 * node] + tree[2 * node + 1];
    }
    
    // Range Query
    int query(int node, int start, int end, int l, int r) {
        if (r < start || end < l) return 0;  // Identity for sum
        if (l <= start && end <= r) return tree[node];
        int mid = (start + end) / 2;
        return query(2 * node, start, mid, l, r) +
               query(2 * node + 1, mid + 1, end, l, r);
    }
    
    // Lazy Propagation — Range Update
    void pushDown(int node, int start, int end) {
        if (lazy[node] != 0) {
            int mid = (start + end) / 2;
            tree[2*node] += lazy[node] * (mid - start + 1);
            tree[2*node+1] += lazy[node] * (end - mid);
            lazy[2*node] += lazy[node];
            lazy[2*node+1] += lazy[node];
            lazy[node] = 0;
        }
    }
    
    void rangeUpdate(int node, int start, int end, int l, int r, int val) {
        if (r < start || end < l) return;
        if (l <= start && end <= r) {
            tree[node] += val * (end - start + 1);
            lazy[node] += val;
            return;
        }
        pushDown(node, start, end);
        int mid = (start + end) / 2;
        rangeUpdate(2*node, start, mid, l, r, val);
        rangeUpdate(2*node+1, mid+1, end, l, r, val);
        tree[node] = tree[2*node] + tree[2*node+1];
    }
}

1. A query visits O(log n) nodes because?

Explanation

Standard segment decomposition covers any range with ≤2 nodes per level.

2. Lazy propagation exists to?

Explanation

Push tags only along visited paths.

3. BIT vs segment tree: BIT wins when?

Explanation

BIT is shorter and faster for prefix sums; segtree is general.
