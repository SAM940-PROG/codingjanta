Intuition

Match algorithm to weights: BFS (unweighted), Dijkstra (≥0), Bellman-Ford (negative), Floyd (all-pairs, small n).

Learn: BFS (unweighted), Dijkstra, Bellman-Ford, Floyd-Warshall, 0-1 BFS  ·  Practice: Warm-ups -> Medium -> Hard

How to recognize this pattern

Reach for it when:
  • 'Shortest/fastest/cheapest route' with weights.
  • Non-negative weights → Dijkstra; negative → Bellman-Ford; tiny n all-pairs → Floyd.
  • Unweighted → plain BFS (don't deploy Dijkstra).
  • Minimize the maximum edge? Sort + DSU may beat shortest-path.
Red flags — probably NOT this:
  • Negative cycle reachability needed — detect, don't route.
  • Only connectivity matters — BFS/DFS suffices.

Worked example — Network Delay Time

Problem. n=4, edges [[2,1,1],[2,3,1],[3,4,1]], source 2. Time for all to receive?

  1. What should we notice? Single-source shortest + max = broadcast time; unreachable ⇒ −1.
  2. Naive thought. Try all routes per node: exponential without structure.
  3. Key observation. Dijkstra settles nodes in final order: extract-min is done forever (weights ≥ 0); relax neighbors.
  4. Optimized strategy. dist=[∞,0,∞,∞] → settle 2 (0): d1=1,d3=1 → settle 1 (1): nothing → settle 3 (1): d4=2 → settle 4. dist=[1,0,1,2].
  5. Step-by-step. Bellman-Ford twin: relax all edges n−1 times; one more improving pass proves a negative cycle.
  6. Final answer. max = 2.
  7. Complexity. O((V+E) log V) with a heap; skip stale PQ entries.
  8. What to remember. Settle-in-order + relax. Always ask: can weights be negative?

Topic 15 · Shortest Path Algorithms

When would you actually use this? Use Dijkstra for non-negative weighted graphs, Bellman-Ford for negative weights, or BFS for unweighted graphs. Choose based on edge weights and constraints.

Algorithm — Dijkstra's (Non-negative weights)

// O((V + E) log V) with PriorityQueue
// SSSP: Single-Source Shortest Path
int[] dijkstra(int n, List<List<int[]>> adj, int src) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;
    
    // {distance, node}
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, src});
    
    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int d = curr[0], u = curr[1];
        if (d > dist[u]) continue;  // Skip outdated entries
        
        for (int[] edge : adj.get(u)) {
            int v = edge[0], w = edge[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.offer(new int[]{dist[v], v});
            }
        }
    }
    return dist;
}

Algorithm — Bellman-Ford (Handles negative weights)

// O(V × E) — can detect negative cycles
int[] bellmanFord(int n, int[][] edges, int src) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;
    
    for (int i = 0; i < n - 1; i++) {
        for (int[] edge : edges) {
            int u = edge[0], v = edge[1], w = edge[2];
            if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
            }
        }
    }
    
    // Check for negative cycles
    for (int[] edge : edges) {
        int u = edge[0], v = edge[1], w = edge[2];
        if (dist[u] != Integer.MAX_VALUE && dist[u] + w < dist[v]) {
            throw new RuntimeException("Negative cycle detected!");
        }
    }
    return dist;
}

Algorithm — Floyd-Warshall (All-Pairs)

// O(V³) — All pairs shortest path
int[][] floydWarshall(int n, int[][] adj) {
    int[][] dist = new int[n][n];
    int INF = (int) 1e9;
    
    // Initialize
    for (int[] row : dist) Arrays.fill(row, INF);
    for (int i = 0; i < n; i++) dist[i][i] = 0;
    for (int[] edge : edges) dist[edge[0]][edge[1]] = edge[2];
    
    // DP
    for (int k = 0; k < n; k++)
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (dist[i][k] + dist[k][j] < dist[i][j])
                    dist[i][j] = dist[i][k] + dist[k][j];
    
    return dist;
}

Algorithm — 0-1 BFS (Edge weights 0 or 1)

// O(V + E) using Deque
int[] bfs01(int n, List<List<int[]>> adj, int src) {
    int[] dist = new int[n];
    Arrays.fill(dist, Integer.MAX_VALUE);
    dist[src] = 0;
    Deque<Integer> deque = new ArrayDeque<>();
    deque.offerFirst(src);
    
    while (!deque.isEmpty()) {
        int u = deque.pollFirst();
        for (int[] edge : adj.get(u)) {
            int v = edge[0], w = edge[1];
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                if (w == 0) deque.offerFirst(v);
                else deque.offerLast(v);
            }
        }
    }
    return dist;
}

1. Dijkstra breaks with?

Explanation

2. Stale PQ entries (old, larger distance) should be?

Explanation

Lazy deletion keeps decrease-key O(log n)-free and stays correct.

3. Unweighted shortest path: use?

Explanation
