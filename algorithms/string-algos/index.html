Intuition

KMP/Z/Rabin-Karp make matching linear via prefix structure; Manacher for palindromes. Know when built-ins suffice.

Learn: KMP, Z-algorithm, Rabin-Karp, Manacher's, suffix arrays  ·  Practice: Warm-ups -> Medium -> Hard

How to recognize this

Reach for it when: Pattern matching on 10⁵+ text (KMP/Z/rolling hash); Palindrome enumeration (Manacher); Repeated-substring / border structure (prefix function).

Red flags: Short texts — built-in indexOf is fine; Single queries — don't build an automaton.

Worked example — KMP on a short pattern

Problem. Find the first occurrence of pattern "abab" in text "aababab".

  1. What should we notice. Repeated prefixes/suffixes inside the pattern are exactly what KMP reuses instead of re-scanning text.
  2. Naive thought. Check every start position: O(n·m).
  3. Key observation. Build the prefix table pi: pi[i] = longest proper prefix that is also a suffix of pattern[0..i].
  4. Prefix table of "abab". pi = [0, 0, 1, 2]. ("ab" is both a prefix and a suffix at the end.)
  5. Matching. On a text/pattern mismatch, fall back to pi[k-1] rather than restarting at the next text pointer.
  6. Result. The match starts at text index 1 ("abab" from position 1). Total work O(n + m).
  7. What to remember. The prefix table is the whole algorithm. Manacher (palindromes) and Z-function (prefix matches) use the same "reuse prior structure" idea.

Algorithm — KMP (Knuth-Morris-Pratt)

// Pattern matching in O(n + m)
// lps[i] = length of longest proper prefix of pattern[0..i] which is also a suffix
int[] computeLPS(String pattern) {
    int m = pattern.length();
    int[] lps = new int[m];
    int len = 0, i = 1;
    while (i < m) {
        if (pattern.charAt(i) == pattern.charAt(len)) {
            lps[i++] = ++len;
        } else if (len > 0) {
            len = lps[len - 1];
        } else {
            lps[i++] = 0;
        }
    }
    return lps;
}

List<Integer> kmpSearch(String text, String pattern) {
    int[] lps = computeLPS(pattern);
    List<Integer> matches = new ArrayList<>();
    int i = 0, j = 0;
    while (i < text.length()) {
        if (text.charAt(i) == pattern.charAt(j)) { i++; j++; }
        if (j == pattern.length()) {
            matches.add(i - j);
            j = lps[j - 1];
        } else if (i < text.length() && text.charAt(i) != pattern.charAt(j)) {
            if (j > 0) j = lps[j - 1];
            else i++;
        }
    }
    return matches;
}

Algorithm — Rabin-Karp (Rolling Hash)

// O(n + m) average, O(nm) worst — good for multiple pattern search
long BASE = 31, MOD = 1_000_000_007;

long hash(String s, int len) {
    long h = 0, power = 1;
    for (int i = 0; i < len; i++) {
        h = (h + (s.charAt(i) - 'a' + 1) * power) % MOD;
        power = power * BASE % MOD;
    }
    return h;
}

// Rolling: remove leftmost char, add new rightmost char
// newHash = (oldHash - (oldChar - 'a' + 1)) / BASE + (newChar - 'a' + 1) * BASE^(len-1)

Algorithm — Z-Algorithm

// z[i] = length of longest substring starting at i that is also a prefix
// O(n) — alternative to KMP for pattern matching
int[] zFunction(String s) {
    int n = s.length();
    int[] z = new int[n];
    int l = 0, r = 0;
    for (int i = 1; i < n; i++) {
        if (i < r) z[i] = Math.min(r - i, z[i - l]);
        while (i + z[i] < n && s.charAt(z[i]) == s.charAt(i + z[i])) z[i]++;
        if (i + z[i] > r) { l = i; r = i + z[i]; }
    }
    return z;
}

// Match found at position i where z[i] == pattern.length()

Algorithm — Manacher's (Longest Palindrome)

// Find all palindromic substrings / longest palindromic substring in O(n)
String manacher(String s) {
    // Transform: "abc" -> "^#a#b#c#$"
    StringBuilder t = new StringBuilder("^#");
    for (char c : s.toCharArray()) { t.append(c); t.append('#'); }
    t.append('$');
    String T = t.toString();
    int n = T.length();
    int[] p = new int[n]; // p[i] = radius of palindrome centered at i
    int center = 0, right = 0;
    
    for (int i = 1; i < n - 1; i++) {
        int mirror = 2 * center - i;
        if (i < right) p[i] = Math.min(right - i, p[mirror]);
        while (T.charAt(i + p[i] + 1) == T.charAt(i - p[i] - 1)) p[i]++;
        if (i + p[i] > right) { center = i; right = i + p[i]; }
    }
    
    // Find longest
    int maxLen = 0, maxCenter = 0;
    for (int i = 1; i < n - 1; i++) {
        if (p[i] > maxLen) { maxLen = p[i]; maxCenter = i; }
    }
    int start = (maxCenter - maxLen) / 2;
    return s.substring(start, start + maxLen);
}
