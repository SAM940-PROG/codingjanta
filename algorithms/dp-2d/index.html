Topic 19 · Dynamic Programming — 2D / Grid

LevelC
Prerequisites1D DP, arrays, basic recursion
Estimated time90+ min
ProgressionWarm-up → Easy → Medium → Hard
Learn → Understand → Dry run → Warm-up → Easy → Medium → Hard → Review

Intuition

Two-dimensional state for grids and string pairs (LCS, edit distance). Draw the table; transitions read off neighbors.

Learn: 2D DP, LCS, edit distance, grid paths, palindromic subsequences  ·  Practice: Warm-ups -> Medium -> Hard

How to recognize this pattern

Reach for it when:
  • Grid paths with moves/obstacles.
  • Two strings (LCS, edit distance, alignment).
  • State naturally needs (i,j).
  • Interval-free 2D structure.
Red flags — probably NOT this:
  • Range over one array with choices — interval DP instead.
  • Subsets with bitmask size ≤ 20 — bitmask DP.

Worked example — Unique Paths 3×3

Problem. Moves right/down only. Paths from corner to corner?

  1. What should we notice? Cell (i,j) is reachable from top + left: dp[i][j]=dp[i−1][j]+dp[i][j−1]; first row/col = 1.
  2. Naive thought. Enumerate all paths: exponential.
  3. Key observation. Fill row by row; neighbors are already final when you arrive.
  4. Optimized strategy. Row0: 1 1 1. Row1: 1 2 3. Row2: 1 3 6.
  5. Step-by-step. LCS twin: match→diag+1 else max(top,left) — same grid walk, different merge.
  6. Final answer. 6.
  7. Complexity. O(n·m) time; two rows suffice unless reconstructing.
  8. What to remember. Draw the table; transitions read off neighbors. Bases = first row/col.

Interactive dry run — Minimum path sum table

Each cell reads only from above and left; filling order guarantees those are already final.

Quick reference

Topic 19 · Dynamic Programming — 2D / Grid

When would you actually use this? Use 2D DP when the problem involves a grid or two-dimensional state. Each cell depends on previous cells -- commonly used for sequences, paths, and subsequences.

Algorithms

// ── Unique Paths ──
int uniquePaths(int m, int n) {
    int[][] dp = new int[m][n];
    Arrays.fill(dp[0], 1);
    for (int i = 0; i < m; i++) dp[i][0] = 1;
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = dp[i-1][j] + dp[i][j-1];
    return dp[m-1][n-1];
}

// ── Longest Common Subsequence (LCS) ──
int lcs(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (s1.charAt(i-1) == s2.charAt(j-1))
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
    return dp[m][n];
}

// ── Edit Distance (Levenshtein) ──
int editDistance(String word1, String word2) {
    int m = word1.length(), n = word2.length();
    int[][] dp = new int[m + 1][n + 1];
    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (word1.charAt(i-1) == word2.charAt(j-1))
                dp[i][j] = dp[i-1][j-1];
            else
                dp[i][j] = 1 + Math.min(dp[i-1][j-1], Math.min(dp[i-1][j], dp[i][j-1]));
    return dp[m][n];
}

// ── Minimum Path Sum ──
int minPathSum(int[][] grid) {
    int m = grid.length, n = grid[0].length;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++) {
            if (i == 0 && j == 0) continue;
            else if (i == 0) grid[i][j] += grid[i][j-1];
            else if (j == 0) grid[i][j] += grid[i-1][j];
            else grid[i][j] += Math.min(grid[i-1][j], grid[i][j-1]);
        }
    return grid[m-1][n-1];
}

// ── Longest Palindromic Subsequence ──
int longestPalinSubseq(String s) {
    int n = s.length();
    int[][] dp = new int[n][n];
    for (int i = n - 1; i >= 0; i--) {
        dp[i][i] = 1;
        for (int j = i + 1; j < n; j++) {
            if (s.charAt(i) == s.charAt(j)) dp[i][j] = dp[i+1][j-1] + 2;
            else dp[i][j] = Math.max(dp[i+1][j], dp[i][j-1]);
        }
    }
    return dp[0][n-1];
}

Warm-Up Problems

Warm-up Unique Paths. Given an m x n grid, find the number of unique paths from top-left to bottom-right.
Warm-up LCS Length. Given two strings, find the length of their longest common subsequence.
Warm-up Min Path Sum. Given a grid of numbers, find the path from top-left to bottom-right with minimum sum.

Explanation

Explanation
