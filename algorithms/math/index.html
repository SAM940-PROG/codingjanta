Intuition

GCD, sieve, fast pow, modular arithmetic, factorization. Most contest math is these five plus combinatorics formulas.

Learn: GCD/LCM, fast exponentiation, sieve, prime factorization, modular arithmetic, Euler's totient  ·  Practice: Warm-ups -> Easy -> Medium -> Hard

How to recognize this

Reach for it when: Prime/divisibility/modular-arithmetic phrasing; Counting/combinatorics with large answers (mod 1e9+7); GCD/power/exponent patterns; Constraints like 10¹² (O(√n) max) or 10⁶ (sieve).

Red flags: Floating-point equality without epsilon; Huge exponents without modular reduction; Assuming primality — sieve or Miller-Rabin first.

Worked example — GCD and LCM

Problem. Compute gcd(48, 36) and lcm(48, 36).

  1. What should we notice? "Greatest common divisor" almost always means Euclid's algorithm.
  2. Naive thought. Factor both numbers and intersect prime factors — correct but slow for large inputs.
  3. Key observation. gcd(a, b) = gcd(b, a mod b); the remainder strictly shrinks, so it terminates in O(log min(a,b)).
  4. Compute. gcd(48, 36) → gcd(36, 12) → gcd(12, 0) = 12.
  5. LCM. lcm = a / gcd · b = 48 / 12 · 36 = 144. Divide first to avoid overflow.
  6. Complexity. O(log min(a,b)) time, O(1) space (iterative).
  7. What to remember. Always divide before multiplying in lcm; for modular work use modular inverses via extended Euclid.

Interactive dry run — Euclid's algorithm

Each step replaces (a, b) with (b, a mod b) until the remainder is zero.

Algorithms

// ── GCD & LCM ──
int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }
long lcm(long a, long b) { return a / gcd((int)a, (int)b) * b; }

// ── Fast Exponentiation (Binary Exponentiation) ──
long power(long base, long exp, long mod) {
    long result = 1;
    base %= mod;
    while (exp > 0) {
        if ((exp & 1) == 1) result = result * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return result;
}

// ── Modular Inverse (when mod is prime) ──
long modInverse(long a, long mod) {
    return power(a, mod - 2, mod);  // Fermat's little theorem
}

// ── Sieve of Eratosthenes — O(n log log n) ──
boolean[] sieve(int n) {
    boolean[] isPrime = new boolean[n + 1];
    Arrays.fill(isPrime, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; (long) i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i)
                isPrime[j] = false;
        }
    }
    return isPrime;
}

// ── Prime Factorization — O(√n) ──
Map<Integer, Integer> primeFactors(int n) {
    Map<Integer, Integer> factors = new HashMap<>();
    for (int d = 2; (long) d * d <= n; d++) {
        while (n % d == 0) {
            factors.merge(d, 1, Integer::sum);
            n /= d;
        }
    }
    if (n > 1) factors.merge(n, 1, Integer::sum);
    return factors;
}

// ── Euler's Totient Function φ(n) ──
int eulerTotient(int n) {
    int result = n;
    for (int p = 2; (long) p * p <= n; p++) {
        if (n % p == 0) {
            while (n % p == 0) n /= p;
            result -= result / p;
        }
    }
    if (n > 1) result -= result / n;
    return result;
}

// ── nCr (Combinations) with mod ──
long[] fact, invFact;
void precompute(int n, long mod) {
    fact = new long[n + 1]; invFact = new long[n + 1];
    fact[0] = 1;
    for (int i = 1; i <= n; i++) fact[i] = fact[i-1] * i % mod;
    invFact[n] = power(fact[n], mod - 2, mod);
    for (int i = n - 1; i >= 0; i--) invFact[i] = invFact[i+1] * (i+1) % mod;
}
long nCr(int n, int r, long mod) {
    if (r < 0 || r > n) return 0;
    return fact[n] % mod * invFact[r] % mod * invFact[n-r] % mod;
}

// ── Matrix Exponentiation (for linear recurrences) ──
long[][] matMul(long[][] A, long[][] B, long mod) {
    int n = A.length, m = B[0].length, k = B.length;
    long[][] C = new long[n][m];
    for (int i = 0; i < n; i++)
        for (int j = 0; j < m; j++)
            for (int p = 0; p < k; p++)
                C[i][j] = (C[i][j] + A[i][p] * B[p][j]) % mod;
    return C;
}

long[][] matPow(long[][] M, long exp, long mod) {
    int n = M.length;
    long[][] result = new long[n][n];
    for (int i = 0; i < n; i++) result[i][i] = 1; // Identity
    while (exp > 0) {
        if ((exp & 1) == 1) result = matMul(result, M, mod);
        M = matMul(M, M, mod);
        exp >>= 1;
    }
    return result;
}

Check yourself

Three questions. Predict before you peek, then verify against the lesson.

1. gcd(48, 36) using Euclid is...

Explanation

48,36 -> 36,12 -> 12,0, so the gcd is 12.

2. Why compute a / gcd * b instead of a * b / gcd for the LCM?

Explanation

Divide first to keep the intermediate value small.

3. A sieve of Eratosthenes finds all primes up to n in...

Explanation

Each composite is crossed out by its smallest prime; the total work is O(n log log n).
