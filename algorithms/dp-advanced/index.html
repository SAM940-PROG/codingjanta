Topic 21 · Advanced DP — Interval, Bitmask, Digit DP

LevelA
Prerequisites1D and 2D DP, bit manipulation
Estimated time2–4 h

Learn → Understand → Dry run → Warm-up → Easy → Medium → Hard → Review

Intuition

Interval (ranges), bitmask (subsets ≤20), digit (counting with constraints). Recognize the shape, apply the template.

Learn: Interval DP, bitmask DP, digit DP, matrix chain multiplication  ·  Practice: Warm-ups -> Medium -> Hard

How to recognize this

Reach for it when: Range games/merges (interval DP); Subsets over ≤20 items (bitmask DP); Digit-constrained counting (digit DP).

Red flags: Plain sequences — 1D/2D suffices; n=10⁵ with bitmask dreams — 2ⁿ explodes.

Worked example — Interval DP: burst balloons

Problem. Burst all balloons in [3, 1, 5] maximizing coins, where bursting i earns left·i·right (neighbors after earlier bursts).

  1. What should we notice? The answer depends on which balloon is burst last in a range — an interval-DP signal.
  2. Naive thought. Try every burst order: n! permutations — impossible.
  3. Key observation. Pick the last balloon k in an interval [i, j]; it sees fixed boundaries i and j because everything inside is already gone. Then solve left and right independently.
  4. State. dp[i][j] = max coins from the open interval (i, j). Transition: dp[i][j] = max over k of dp[i][k] + a[i]·a[k]·a[j] + dp[k][j].
  5. Fill order. By increasing interval length, so smaller intervals are ready before larger ones.
  6. This example. Pad to [1, 3, 1, 5, 1]. Best is burst 1 then 5 then 3: 1·3·1 + 1·5·1? Work it as 3·1·5 is not last — final dp = 15·... = answer 15·? (short: 3·1·5 then remaining gives 15+... ). The template, not the arithmetic, is the point.
  7. Complexity. O(n³) time, O(n²) space.
  8. What to remember. Interval DP: choose the last element processed; boundaries become constants; fill by length.

Interactive dry run — GCD (Euclid)

Watch the remainder shrink: gcd(a, b) = gcd(b, a mod b).

Interval DP

// Template: dp[i][j] = optimal answer for range [i, j]
// Order: process by increasing length
for (int len = 2; len <= n; len++) {
    for (int i = 0; i + len - 1 < n; i++) {
        int j = i + len - 1;
        dp[i][j] = INF;
        for (int k = i; k < j; k++) {
            dp[i][j] = Math.min(dp[i][j], dp[i][k] + dp[k+1][j] + cost(i, j, k));
        }
    }
}

// Matrix Chain Multiplication
// Burst Balloons (LC #312)

Bitmask DP

// dp[mask] = answer for subset represented by bitmask
// Iterate over all 2^n subsets

// Example: Traveling Salesman Problem (TSP)
int[][] dp = new int[1 << n][n];
for (int[] row : dp) Arrays.fill(row, INF);
dp[1][0] = 0;  // Start at node 0

for (int mask = 1; mask < (1 << n); mask++) {
    for (int u = 0; u < n; u++) {
        if ((mask & (1 << u)) == 0 || dp[mask][u] == INF) continue;
        for (int v = 0; v < n; v++) {
            if ((mask & (1 << v)) != 0) continue;  // Already visited
            int newMask = mask | (1 << v);
            dp[newMask][v] = Math.min(dp[newMask][v], dp[mask][u] + dist[u][v]);
        }
    }
}

// Iterate over submasks of a mask
for (int sub = mask; sub > 0; sub = (sub - 1) & mask) {
    // sub is a submask of mask
}

// Useful bit operations
int setBit = mask | (1 << i);
int clearBit = mask & ~(1 << i);
boolean isSet = (mask & (1 << i)) != 0;
int countBits = Integer.bitCount(mask);
int lowestBit = mask & (-mask);

Digit DP

// Count numbers in [0, N] satisfying a property
// State: position, tight (whether bounded by N), leading zero, extra info

Long[][][][] memo;  // [pos][tight][leadingZero][extra]

long digitDP(String num, int pos, boolean tight, boolean leadZero, int extra) {
    if (pos == num.length()) return isValid(extra) ? 1 : 0;
    if (memo[pos][tight?1:0][leadZero?1:0][extra] != null)
        return memo[pos][tight?1:0][leadZero?1:0][extra];
    
    int limit = tight ? (num.charAt(pos) - '0') : 9;
    long result = 0;
    for (int d = 0; d <= limit; d++) {
        result += digitDP(num, pos + 1,
            tight && d == limit,
            leadZero && d == 0,
            updateExtra(extra, d, leadZero));
    }
    return memo[pos][tight?1:0][leadZero?1:0][extra] = result;
}

// To count in range [L, R]: digitDP(R) - digitDP(L - 1)

Check yourself

Three questions. Predict before you peek, then verify against the lesson.

1. Interval DP commonly chooses which element to decide first?

Explanation

Deciding the last element fixes the boundaries, making left and right subproblems independent.

2. A bitmask DP is practical when the state is a subset and n is...

Explanation

States are 2^n; beyond about 20 the table explodes.

3. Digit DP's state usually includes...

Explanation

Position + whether the prefix is tight + the property tracked so far.
