Topic 6 · Prefix Sum & Difference Arrays

LevelC
PrerequisitesArrays, basic loops
Estimated time45–60 min
ProgressionWarm-up → Easy → Medium → Hard
Learn → Understand → Dry run → Warm-up → Easy → Medium → Hard → Review

Intuition

Precompute cumulative sums once; every range sum becomes O(1). Difference arrays are the mirror: O(1) range adds.

Learn: 1D prefix sum, 2D prefix sum, difference array, prefix sum + hash map  ·  Practice: Warm-ups -> Easy -> Medium -> Hard

How to recognize this pattern

Reach for it when:
  • Many range-sum/count queries on a static array.
  • 'Subarray with sum K / divisible by K' phrasing.
  • Range ADD updates followed by final values (difference array).
  • 2D submatrix sums.
Red flags — probably NOT this:
  • Point updates interleaved with queries — reach for Fenwick/segment tree.
  • Queries need order statistics or max, not sums.
  • Single query only — a direct scan is simpler.

Worked example — Range sum in O(1)

Problem. Array a=[2,4,1,7,3]. Answer sum(1,3).

  1. What should we notice? Repeated range questions → precompute once.
  2. Naive thought. Scan [l,r] per query: O(n) each, O(n·q) total.
  3. Key observation. pref[i] = sum of first i elements turns any range into a subtraction: sum(l,r)=pref[r+1]−pref[l]. For 'sum K' counting, pref[j]−pref[i]=K ⇔ pref[i]=pref[j]−K: a hashmap of past prefs counts it in one pass.
  4. Optimized strategy. Build: pref=[0,2,6,7,14,17]. Query [1,3]: 14−2=12 (4+1+7 ✓).
  5. Step-by-step. Counting twin: a=[1,2,3,−2,5], K=5 — track pref frequencies as you sweep; each position asks 'have I seen pref−K?'
  6. Final answer. sum(1,3)=12.
  7. Complexity. Build O(n); each query O(1). Counting variant O(n) time, O(n) space.
  8. What to remember. Range question + static data → prefix. 'Sum K' → prefix + hashmap.

Quick reference

Topic 6 · Prefix Sum & Difference Arrays

When would you actually use this? Use prefix sums to answer range sum queries in O(1). Use difference arrays to apply range updates in O(1). Essential for interval/range problems.

How To Use This Topic

Before learning this: Arrays, basic loops

Learn this: 1D prefix sum, 2D prefix sum, difference array, prefix sum + hash map

Practice this: Warm-ups -> Easy -> Medium -> Hard

Move on when: You can identify when a range query problem can be solved in O(1) with prefix sums

Algorithm — Prefix Sum

// 1D Prefix Sum
int[] prefix = new int[n + 1];
for (int i = 0; i < n; i++) {
    prefix[i + 1] = prefix[i] + arr[i];
}
// Sum of range [l, r] (0-indexed) = prefix[r+1] - prefix[l]

// 2D Prefix Sum
int[][] prefix = new int[m + 1][n + 1];
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        prefix[i+1][j+1] = grid[i][j] + prefix[i][j+1] + prefix[i+1][j] - prefix[i][j];
// Sum of submatrix (r1,c1) to (r2,c2):
// prefix[r2+1][c2+1] - prefix[r1][c2+1] - prefix[r2+1][c1] + prefix[r1][c1]

Algorithm — Difference Array

// Apply range updates efficiently: add val to all elements in [l, r]
int[] diff = new int[n + 1];
diff[l] += val;
diff[r + 1] -= val;

// Reconstruct array from difference array:
int[] result = new int[n];
result[0] = diff[0];
for (int i = 1; i < n; i++) {
    result[i] = result[i-1] + diff[i];
}

Why?

Prefix sum converts O(n) range queries into O(1). Difference arrays convert O(n) range updates into O(1). Together they're fundamental for range-based problems.

Warm-Up Problems

Warm-up Range Sum. Given an array, build a prefix sum array and answer sum queries for ranges [l, r].
Solution

pref[0]=0; pref[i+1]=pref[i]+a[i]. Query [l,r] = pref[r+1]−pref[l]. O(n) build, O(1) per query.

Warm-up Array Update. Given an array and a series of range additions, apply them efficiently using a difference array.
Solution

diff[l]+=v; diff[r+1]−=v per update (O(1) each); one prefix pass over diff materializes the array.

Warm-up Subarray Sum. Given an array and target k, find if any subarray sums to k using prefix sums and a hash map.
Solution

Sweep running pref; map counts past prefs. At each step add map.get(pref−k, 0), then record pref. O(n).

Check yourself

Three questions. Predict, don't peek — then verify against the lesson.

1. Range [l,r] from pref (pref has n+1 entries)?

Explanation

pref[i] covers the first i elements, so element r lives in pref[r+1].

2. Difference array applies +v to [l,r] by?

Explanation

Two O(1) marks; one reconstruction pass materializes all updates.

3. Sums overflow int when?

Explanation

10⁵ × 10⁹ overflows badly. Reach for long by default.
