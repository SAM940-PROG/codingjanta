How to recognize this

Reach for it when: Bipartite matching / assignment / max flow phrasing; Geometric primitives (hull, sweep line); Win/lose game states (Nim/Grundy).

Red flags: Small enough for brute force / DP; Unweighted shortest path disguised as flow.

Worked example — Nim: who wins?

Problem. Piles [3, 4, 5]. Two players remove any positive number from one pile; the player taking the last object wins. Does the first player win?

  1. What should we notice? Perfect-information impartial game with independent piles — a game-theory signal.
  2. Naive thought. Enumerate every move tree: exponential; hopeless past a handful of piles.
  3. Key observation. A position is losing exactly when the XOR of pile sizes is 0. Whoever moves from XOR 0 must break it; the opponent restores 0.
  4. Compute. 3 XOR 4 = 7; 7 XOR 5 = 2.
  5. Interpret. XOR = 2 (non-zero) → the player to move has a winning strategy.
  6. The winning move. Find a pile whose removal leaves XOR 0. Target pile = pile XOR 2: pile 3 gives 1 — reduce 3 to 1; piles [1,4,5] have XOR 0.
  7. Complexity. O(n) to XOR and O(n) to find the move.
  8. What to remember. XOR-zero is the losing condition. Grundy numbers extend the same idea to general impartial games.

Interactive dry run — Nim XOR

The XOR of the piles decides the winner before any move is made.

Network Flow — Ford-Fulkerson / Dinic's

// Max Flow — Dinic's Algorithm O(V²E)
// Used for: max flow, min cut, bipartite matching, assignment problems
class Dinic {
    int[] level, iter;
    List<int[]>[] graph;  // {to, cap, rev_index}
    
    void addEdge(int from, int to, int cap) {
        graph[from].add(new int[]{to, cap, graph[to].size()});
        graph[to].add(new int[]{from, 0, graph[from].size() - 1});
    }
    
    boolean bfs(int s, int t) {
        level = new int[graph.length];
        Arrays.fill(level, -1);
        Queue<Integer> q = new ArrayDeque<>();
        level[s] = 0;
        q.offer(s);
        while (!q.isEmpty()) {
            int v = q.poll();
            for (int[] e : graph[v]) {
                if (e[1] > 0 && level[e[0]] < 0) {
                    level[e[0]] = level[v] + 1;
                    q.offer(e[0]);
                }
            }
        }
        return level[t] >= 0;
    }
    
    int dfs(int v, int t, int f) {
        if (v == t) return f;
        for (; iter[v] < graph[v].size(); iter[v]++) {
            int[] e = graph[v].get(iter[v]);
            if (e[1] > 0 && level[v] < level[e[0]]) {
                int d = dfs(e[0], t, Math.min(f, e[1]));
                if (d > 0) {
                    e[1] -= d;
                    graph[e[0]].get(e[2])[1] += d;
                    return d;
                }
            }
        }
        return 0;
    }
    
    int maxFlow(int s, int t) {
        int flow = 0;
        while (bfs(s, t)) {
            iter = new int[graph.length];
            int d;
            while ((d = dfs(s, t, Integer.MAX_VALUE)) > 0) flow += d;
        }
        return flow;
    }
}

Computational Geometry Basics

// Cross Product — determines direction of turn
// > 0: counter-clockwise, < 0: clockwise, = 0: collinear
long cross(long[] O, long[] A, long[] B) {
    return (A[0] - O[0]) * (B[1] - O[1]) - (A[1] - O[1]) * (B[0] - O[0]);
}

// Convex Hull — Andrew's Monotone Chain — O(n log n)
List<long[]> convexHull(long[][] points) {
    Arrays.sort(points, (a, b) -> a[0] != b[0] ? Long.compare(a[0], b[0]) : Long.compare(a[1], b[1]));
    List<long[]> hull = new ArrayList<>();
    
    // Lower hull
    for (long[] p : points) {
        while (hull.size() >= 2 && cross(hull.get(hull.size()-2), hull.get(hull.size()-1), p) <= 0)
            hull.remove(hull.size() - 1);
        hull.add(p);
    }
    
    // Upper hull
    int lower = hull.size() + 1;
    for (int i = points.length - 2; i >= 0; i--) {
        while (hull.size() >= lower && cross(hull.get(hull.size()-2), hull.get(hull.size()-1), points[i]) <= 0)
            hull.remove(hull.size() - 1);
        hull.add(points[i]);
    }
    hull.remove(hull.size() - 1);
    return hull;
}

Game Theory — Sprague-Grundy Theorem

// Nim Game: XOR of all pile sizes
// If XOR != 0, first player wins; if XOR == 0, second player wins
boolean nimWin(int[] piles) {
    int xor = 0;
    for (int p : piles) xor ^= p;
    return xor != 0;
}

// Grundy Number (Sprague-Grundy)
// G(position) = mex({G(next_positions)})
// mex = minimum excludant (smallest non-negative integer not in set)
int mex(Set<Integer> set) {
    int m = 0;
    while (set.contains(m)) m++;
    return m;
}

Check yourself

Three questions. Predict before you peek, then verify against the lesson.

1. In Nim, a position is losing exactly when...

Explanation

A zero XOR cannot be left at zero by the mover; the opponent restores zero every turn.

2. A geometry problem should usually avoid floating point because...

Explanation

Prefer integer cross products for orientation/collinearity; use epsilons only when geometry truly is continuous.

3. Dinic's algorithm computes...

Explanation

Dinic is a max-flow algorithm; matching and assignment are reductions to max flow.
