Intuition

Ordering unlocks everything: binary search, two pointers, greedy. Know O(n log n) sorts, when built-ins suffice, and how comparators steer them.

Learn: Merge sort, quick sort, built-in sort, comparators  ·  Practice: Warm-ups -> Easy -> Medium problems

How to recognize this

Reach for it when: Order enables the next technique (binary search, two pointers, greedy); k-th order / duplicates / custom keys; Nearly-sorted or tiny input (insertion/counted quirks).

Red flags: O(n) counting/frequency decides it — don't sort first; Top-k from a stream — heap wins.

Worked example — Merging intuition

Problem. Merge [3,8] and [2,5].

  1. What should we notice? Both sorted ⇒ the next output is always a head.
  2. Naive thought. Re-sort the concatenation: O(n log n) for an O(n) job.
  3. Key observation. Two fingers on the heads; emit the smaller, advance. Exhaustion appends the rest.
  4. Optimized strategy. 3 vs 2 → 2; 3 vs 5 → 3; 8 vs 5 → 5; 8 → done: [2,3,5,8].
  5. Step-by-step. Dutch-flag twin: three regions (0s, unknown, 2s) with the same head-pointer discipline.
  6. Final answer. [2,3,5,8].
  7. Complexity. Merge O(n); mergesort O(n log n), O(n) extra (O(1) with care in contests: use built-ins).
  8. What to remember. Sorted halves merge linearly. In contests: sort with the library, spend insight elsewhere.

Quick reference

Topic 3 · Sorting Algorithms

When would you actually use this? Use sorting when you need ordered data. Many problems become easy once sorted -- binary search, two pointers, and greedy approaches all rely on sorted input.

How To Use This Topic

Before learning this: Arrays, basic loops, Big-O

Learn this: Merge sort, quick sort, built-in sort, comparators

Practice this: Warm-ups -> Easy -> Medium problems

Move on when: You know when sorting unlocks a solution and which O(n log n) sort to use

Why?

Sorting is a prerequisite for many algorithms: binary search, two pointers, greedy approaches. Knowing when and which sort to use is critical.

Easy — Bubble Sort, Selection Sort, Insertion Sort

// Bubble Sort — O(n²) time, O(1) space, STABLE
public void bubbleSort(int[] arr) {
    int n = arr.length;
    for (int i = 0; i < n - 1; i++) {
        boolean swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j]; arr[j] = arr[j + 1]; arr[j + 1] = temp;
                swapped = true;
            }
        }
        if (!swapped) break;  // Early termination if already sorted
    }
}

// Selection Sort — O(n²) time, O(1) space, NOT STABLE
public void selectionSort(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < arr.length; j++) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        int temp = arr[i]; arr[i] = arr[minIdx]; arr[minIdx] = temp;
    }
}

// Insertion Sort — O(n²) time, O(1) space, STABLE
// Best for nearly sorted data — O(n) best case
public void insertionSort(int[] arr) {
    for (int i = 1; i < arr.length; i++) {
        int key = arr[i], j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

Medium — Merge Sort, Quick Sort

// Merge Sort — O(n log n) time, O(n) space, STABLE
// Excellent for linked lists and external sorting
public void mergeSort(int[] arr, int left, int right) {
    if (left >= right) return;
    int mid = left + (right - left) / 2;
    mergeSort(arr, left, mid);
    mergeSort(arr, mid + 1, right);
    merge(arr, left, mid, right);
}

private void merge(int[] arr, int left, int mid, int right) {
    int[] temp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) temp[k++] = arr[i++];
        else temp[k++] = arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];
    System.arraycopy(temp, 0, arr, left, temp.length);
}

// Quick Sort — O(n log n) avg, O(n²) worst, O(log n) space, NOT STABLE
// Fastest in practice for random data
public void quickSort(int[] arr, int low, int high) {
    if (low >= high) return;
    int pivotIdx = partition(arr, low, high);
    quickSort(arr, low, pivotIdx - 1);
    quickSort(arr, pivotIdx + 1, high);
}

private int partition(int[] arr, int low, int high) {
    // Randomized pivot to avoid worst case
    int randIdx = low + (int)(Math.random() * (high - low + 1));
    int temp = arr[randIdx]; arr[randIdx] = arr[high]; arr[high] = temp;
    
    int pivot = arr[high], i = low;
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;
            i++;
        }
    }
    temp = arr[i]; arr[i] = arr[high]; arr[high] = temp;
    return i;
}

Hard — Counting Sort, Radix Sort, Heap Sort

// Counting Sort — O(n + k) time, O(k) space, STABLE
// Use when range of values (k) is small relative to n
public void countingSort(int[] arr) {
    int max = Arrays.stream(arr).max().getAsInt();
    int min = Arrays.stream(arr).min().getAsInt();
    int range = max - min + 1;
    int[] count = new int[range], output = new int[arr.length];
    for (int val : arr) count[val - min]++;
    for (int i = 1; i < range; i++) count[i] += count[i - 1];
    for (int i = arr.length - 1; i >= 0; i--) {
        output[count[arr[i] - min] - 1] = arr[i];
        count[arr[i] - min]--;
    }
    System.arraycopy(output, 0, arr, 0, arr.length);
}

// Radix Sort — O(d × (n + k)) time, O(n + k) space, STABLE
// d = number of digits, k = radix (10 for decimal)
public void radixSort(int[] arr) {
    int max = Arrays.stream(arr).max().getAsInt();
    for (int exp = 1; max / exp > 0; exp *= 10) {
        countingSortByDigit(arr, exp);
    }
}

// Heap Sort — O(n log n) time, O(1) space, NOT STABLE
// In-place but not cache friendly
public void heapSort(int[] arr) {
    int n = arr.length;
    for (int i = n / 2 - 1; i >= 0; i--) heapify(arr, n, i);
    for (int i = n - 1; i > 0; i--) {
        int temp = arr[0]; arr[0] = arr[i]; arr[i] = temp;
        heapify(arr, i, 0);
    }
}

private void heapify(int[] arr, int n, int i) {
    int largest = i, left = 2 * i + 1, right = 2 * i + 2;
    if (left < n && arr[left] > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;
    if (largest != i) {
        int temp = arr[i]; arr[i] = arr[largest]; arr[largest] = temp;
        heapify(arr, n, largest);
    }
}
