How to recognize this

Reach for it when: Subsets over n≤20 (bitmask enumeration); XOR / single-number / parity tricks; Lowbit / power-of-two / popcount micro-ops; State compression in DP.

Red flags: Shifts ≥31 on int without long; Confusing AND/OR masks — draw the bits.

Worked example — Single number via XOR

Problem. Every value in [4, 1, 2, 1, 2] appears twice except one. Find the unique value in O(n) time and O(1) space.

  1. What should we notice? "Appears twice" plus "find the odd one" is the classic XOR-partition signal.
  2. Naive thought. Count frequencies in a HashMap: O(n) time but O(n) extra space.
  3. Key observation. x XOR x = 0 and x XOR 0 = x, and XOR is associative/commutative. Pairing is automatic.
  4. Compute. 4 XOR 1 = 5; 5 XOR 2 = 7; 7 XOR 1 = 6; 6 XOR 2 = 4.
  5. Final answer. 4.
  6. Complexity. O(n) time, O(1) space.
  7. What to remember. XOR cancels duplicates. The same trick underlies "find the missing number" and "two numbers appearing once."

Interactive dry run — Subset enumeration

Every mask from 0 to 2³−1 is one subset; set bits name the chosen elements.

Essential Bitwise Operations

// ── Basics ──
a & b         // AND — both bits 1
a | b         // OR — at least one bit 1
a ^ b         // XOR — different bits → 1, same → 0
~a            // NOT — flip all bits
a << k        // Left shift — multiply by 2^k
a >> k        // Right shift (arithmetic) — divide by 2^k
a >>> k       // Unsigned right shift

// ── Common Tricks ──
x & 1                    // Check if odd (last bit)
x & (x - 1)             // Clear lowest set bit
x & (-x)                // Isolate lowest set bit
Integer.bitCount(x)      // Count set bits (popcount)
Integer.highestOneBit(x) // Highest power of 2 ≤ x
Integer.numberOfLeadingZeros(x)
Integer.numberOfTrailingZeros(x)

// Check if power of 2
boolean isPow2 = x > 0 && (x & (x - 1)) == 0;

// Get/Set/Clear/Toggle bit at position i
boolean isSet = (x & (1 << i)) != 0;
int setBit   = x | (1 << i);
int clearBit = x & ~(1 << i);
int toggleBit = x ^ (1 << i);

// XOR Properties
// a ^ 0 = a
// a ^ a = 0
// a ^ b ^ a = b  (find missing/single element)

// Generate all subsets of a set (bitmask)
for (int mask = 0; mask < (1 << n); mask++) {
    for (int i = 0; i < n; i++) {
        if ((mask & (1 << i)) != 0) {
            // element i is in this subset
        }
    }
}

// Swap without temp
a ^= b; b ^= a; a ^= b;

Check yourself

Three questions. Predict before you peek, then verify against the lesson.

1. x & (x - 1) does what?

Explanation

Subtracting 1 flips the lowest set bit and below; AND clears it. Used to count set bits.

2. XOR of a list where every value appears twice except one leaves...

Explanation

x ^ x = 0, so all pairs cancel; the unpaired value survives.

3. Why write 1L << 40 instead of 1 << 40?

Explanation

Java int shifts are mod 32; use a long literal for shifts of 31 or more.
