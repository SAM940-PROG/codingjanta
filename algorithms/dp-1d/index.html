Intuition

Overlapping subproblems + optimal substructure: define state, transition, base. 1D first (stairs, robber, LIS, coin change).

Learn: DP framework, state definition, transition, base case, 1D patterns (LIS, coin change, house robber)  ·  Practice: Warm-ups -> Easy -> Medium -> Hard

How to recognize this pattern

Reach for it when:
  • Overlapping subproblems + optimal substructure.
  • Counting ways / min-max over sequences (stairs, robber, LIS, coin change).
  • 'Can you reach / how many ways' on a line.
  • Recursion that recomputes the same states.
Red flags — probably NOT this:
  • Greedy choice is provably safe — DP still works but wastes effort.
  • No overlapping subproblems (plain divide & conquer).
  • State needs 2+ dimensions — step up to 2D.

Worked example — Climbing Stairs (n=4)

Problem. 1 or 2 steps at a time. Ways to reach step 4?

  1. What should we notice? Ways to i come only from i−1 and i−2: dp[i]=dp[i−1]+dp[i−2].
  2. Naive thought. Enumerate all sequences: O(2ⁿ).
  3. Key observation. State = position; transition = last jump size; bases dp[0]=dp[1]=1.
  4. Optimized strategy. dp: [1,1] → dp[2]=2 → dp[3]=3 → dp[4]=5.
  5. Step-by-step. Robber twin: dp[i]=max(dp[i−1], dp[i−2]+nums[i]) — same skeleton, maximizing choice.
  6. Final answer. 5.
  7. Complexity. O(n) time; O(1) with two rolling variables.
  8. What to remember. Name the state first. Write transition, then bases — code last.

Topic 18 · Dynamic Programming — 1D

Algorithm — DP Framework

// 5-Step DP Framework:
// 1. Define state: dp[i] = what does it represent?
// 2. Base case: dp[0] = ?
// 3. Transition: dp[i] = f(dp[i-1], dp[i-2], ...)
// 4. Order: iterate in which direction?
// 5. Answer: dp[n] or max(dp)?

// ── Fibonacci / Climbing Stairs ──
int climbStairs(int n) {
    int a = 1, b = 1;
    for (int i = 2; i <= n; i++) {
        int c = a + b;
        a = b;
        b = c;
    }
    return b;
}

// ── House Robber ──
int rob(int[] nums) {
    int prev2 = 0, prev1 = 0;
    for (int num : nums) {
        int curr = Math.max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}

// ── Longest Increasing Subsequence (LIS) — O(n log n) ──
int lis(int[] nums) {
    List<Integer> tails = new ArrayList<>();
    for (int num : nums) {
        int pos = Collections.binarySearch(tails, num);
        if (pos < 0) pos = -(pos + 1);
        if (pos == tails.size()) tails.add(num);
        else tails.set(pos, num);
    }
    return tails.size();
}

// ── Coin Change ──
int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);
    dp[0] = 0;
    for (int i = 1; i <= amount; i++) {
        for (int coin : coins) {
            if (coin <= i) dp[i] = Math.min(dp[i], dp[i - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}

// ── Maximum Subarray (Kadane's Algorithm) ──
int maxSubArray(int[] nums) {
    int maxSum = nums[0], currSum = nums[0];
    for (int i = 1; i < nums.length; i++) {
        currSum = Math.max(nums[i], currSum + nums[i]);
        maxSum = Math.max(maxSum, currSum);
    }
    return maxSum;
}

// ── Word Break ──
boolean wordBreak(String s, List<String> wordDict) {
    Set<String> words = new HashSet<>(wordDict);
    boolean[] dp = new boolean[s.length() + 1];
    dp[0] = true;
    for (int i = 1; i <= s.length(); i++) {
        for (int j = 0; j < i; j++) {
            if (dp[j] && words.contains(s.substring(j, i))) {
                dp[i] = true;
                break;
            }
        }
    }
    return dp[s.length()];
}
