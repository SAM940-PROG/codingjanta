Contest Mode

The original contest strategy, unchanged.

Key notes

Read — Scan all problems first (first 5 minutes)
Rank — Order by perceived difficulty, not by position
Solve Easy — Start with the easiest problem you can solve correctly
Solve Medium — Move to the next easiest
Skip Stuck — If stuck after 20–30 min, switch problems
Return Later — Come back with fresh eyes
Debug — Fix obvious bugs, don't rewrite from scratch
Submit — Once you have a working solution, submit early

Contest Anti-Patterns to Avoid

⛔ Don't get emotionally attached to one problem. Move on after 20–30 minutes.
⛔ Don't over-engineer. A simple working solution beats a complex broken one.
⛔ Don't skip testing edge cases. Empty input, single element, and duplicates are the most common sources of wrong answers.
⛔ Don't rewrite from scratch. Debug the existing code first.
⛔ Don't ignore time. Track how much time you've spent on each problem.
