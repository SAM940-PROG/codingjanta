How to Use This Guide

This website has two modes:

📖 Learning Mode

Follow the roadmap below. Study topics in order. Do warm-ups before tackling the real problems. This is for building foundations from scratch.

🔍 Reference Mode

Already know the basics? Jump directly to any Java collection, algorithm, or data structure using the navigation sidebar. Use it as an encyclopedia during contests and coding sessions.

One curriculum, two speeds: learn the idea step by step, then use the reference at full speed. Your progress stays on this device.
