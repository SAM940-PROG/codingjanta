Competitive programming Teaching-first

Your Competitive Programming learning path

Go from rusty fundamentals to contest-ready: follow the path in order, or jump straight to any reference when you know what you need. Contest skill decides the sequencing; interview prep comes along for free.

Two ways to use this site. Learn mode: Roadmap → prerequisites → intuition → worked example → dry run → warm-up → Easy → Medium → Hard → review. Reference mode: jump straight to any template, complexity note, or problem list.

The path

Foundations

  • Time & Space Complexity — know if brute force survives before you code.
  • Recursion & Backtracking — shrink, solve, (un)do.
  • Sorting Algorithms — ordering unlocks everything else.

Core patterns

  • Binary Search — discard half the candidates per check.
  • Two Pointers & Sliding Window — O(n²) → O(n) on ordered data.
  • Prefix Sum & Difference Arrays — O(1) range queries and updates.
  • Hashing Patterns — trade memory for speed.
  • Stacks & Monotonic Stacks · Queues & Monotonic Queues — pending work, remembered correctly.
  • Greedy Algorithms — when local optimality is provably enough.
  • Bit Manipulation · String Algorithms — contest vocabulary.

Data structures

  • Linked Lists · Trees · Heaps · Tries · Segment Tree & Fenwick · Sparse Table / LCA / HLD

Graphs

  • BFS / DFS / Topological Sort · Shortest Path · MST · Union-Find

Dynamic programming

  • DP — 1D · DP — 2D / Grid · DP — Knapsack · Advanced DP

Math & endgame

  • Math & Number Theory · Flow / Geometry / Games · Contest Mode

How to work a topic

Learn the intuition, predict behavior on the dry run, clear the warm-ups, then climb Easy → Medium → Hard. Finish with the review checkpoint and the move-on checklist before advancing. Java pages are fast reference — read them as needed, not in order.

Practice & planning

  • Challenge Top-30 — mixed sparring.
  • Preset Catalog — searchable pattern library with Java templates.
  • Mixed-Pattern Practice — hard “which preset?” questions with why-wrong explanations.
  • Pattern Recognition — if-it-has-X-think-Y lookup.
  • Study Schedule — a sane weekly plan.
  • Problem-Solving Checklist — your contest routine.
  • Cheat Sheet — complexity lookup and Java I/O.

Advanced CP track

After the core track: Network Flow, Geometry & Games (Dinic, matching, Nim/Grundy) and Sparse Table, LCA & HLD, with advanced presets (Mo's algorithm, digit DP, suffix automaton, Aho-Corasick, persistent structures) marked Overview where recognition matters more than hand-rolling. Progression: Core DSA → Intermediate CP → Advanced CP.

Contest-day Java: Java Contest Setup — fast input/output, collections done right, and the pitfalls that cost verdicts.

One curriculum, two speeds: learn the idea step by step, then use the reference at full speed. Your progress stays on this device.
